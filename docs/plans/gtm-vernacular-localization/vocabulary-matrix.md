## 2. Paywall & Value Proposition Strings

### Hindi
* **Anchor**: *"सिर्फ 3 ग्राहकों के बकाया पैसे बचने पर पूरे साल का खर्च वसूल!"*
* **CTA**: *"1-क्लिक में अपग्रेड करें (₹1,499 / वर्ष)"*

### Marathi
* **Anchor**: *"फक्त ३ ग्राहकांची थकबाकी वसूल झाली तरी पूर्ण वर्षाचा खर्च निघतो!"*
* **CTA**: *"१-क्लिकमध्ये अपग्रेड करा (₹1,499 / वर्ष)"*

### Bengali
* **Bengali Anchor**: *"মাত্র ৩ জন গ্রাহকের বকেয়া টাকা আদায় হলেই সারা বছরের খরচ উঠে যাবে!"*
* **CTA**: *"১-ক্লিকে আপগ্রেড করুন (₹1,499 / বছর)"*

### Tamil
* **Tamil Anchor**: *"3 வாடிக்கையாளர்களின் பாக்கி வசூலானாலே முழு ஆண்டு செலவும் ஈடுசெய்யப்படும்!"*
* **CTA**: *"1-கிளிக்கில் மேம்படுத்துங்கள் (₹1,499 / ஆண்டு)"*
